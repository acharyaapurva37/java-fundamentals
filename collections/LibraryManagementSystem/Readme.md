Library Management System (Java)

A console-based Java project to practice the Collections Framework and OOP concepts.

Features

Add Books and Members

Issue and Return Books

Prevent duplicate records using HashMap and HashSet

Track availability and transactions

Date format validation (YYYY-MM-DD)

Concepts Used

HashMap, HashSet

equals() & hashCode()

Encapsulation and OOP

Object relationships

Input validation

Structure

Book, Member, IssueRecord, LibraryService, LibraryManager
