# Library Book Management System (Java)

This is a console-based Java application built from scratch to practice
core Java fundamentals such as ArrayList, loops, conditionals, methods,
and object-oriented programming concepts.

The application allows basic management of books in a library using
in-memory storage and a menu-driven interface.

---

## Features

- Add a new book with ID, title, and author
- Prevent duplicate book IDs
- View all books in the library
- Issue a book
- Return a book
- Search for a book by ID
- Menu-driven program with repeat options

---

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

---

## Project Structure

- `Book.java`  
  Represents a single book with:
  - id
  - title
  - author
  - issued status  
  Contains methods related to book behavior.

- `Main.java`  
  Handles:
  - Menu display
  - User input
  - Book list management
  - Core application logic

---

## Key Concepts Practiced

- Class vs Object responsibility
- Managing collections using ArrayList
- Writing clean loop-based search logic
- Preventing duplicate data
- Proper use of boolean flags
- Early return patterns in methods
- Handling edge cases (empty list, invalid ID)
- Building user-friendly console output
