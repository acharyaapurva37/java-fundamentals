# Student Result Management System (Java)

This is a console-based Java application built to practice and strengthen
core Java fundamentals such as arrays, ArrayList, loops, conditionals,
methods, and basic object-oriented programming concepts.

The project is menu-driven and allows basic management of student data
using in-memory storage.

---

## Features

- Add a student with ID, name, and marks
- View all students
- Calculate average marks for a student using student ID
- Find the topper based on total marks
- Menu-driven program with repeat options

---

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

---

## Project Structure

- `Student.java`  
  Represents a single student with id, name, and marks.  
  Contains logic to calculate total and average marks.

- `Main.java`  
  Contains the menu, user interaction, and manages the list of students.
